# Telegram-бот для сбора заявок

Бот проводит пользователя по сценарию заказа сайта, продвижения или доработки сайта, собирает ответы и отправляет заявку менеджеру. В проекте также есть административная панель для управления меню, заявками и ролями.

> **Важно:** бот предоставляется для ознакомительного и некоммерческого использования. Он не предназначен для коммерческого использования.

## Возможности

- Пошаговый сценарий и сбор ответов пользователя.
- Запрос согласия с политикой конфиденциальности перед началом работы.
- Отправка заявок в выбранный Telegram-чат и сохранение в `data/leads.csv`.
- Просмотр, выгрузка и удаление заявок администраторами и менеджерами.
- Административное редактирование текстов и пунктов меню: изменение, скрытие и сброс к исходному виду.
- Редактирование базовых цен, коэффициентов и надбавок из админ-панели.
- Добавление администраторов и менеджеров.
- Перезапуск из админ-панели; при ошибке запуска бот повторяет попытку через 60 секунд.

## Требования

- Python 3.10 или новее.
- Telegram-бот и его токен, полученный у [@BotFather](https://t.me/BotFather).

## Установка и запуск в Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item env.example .env
```

Откройте `.env` и задайте токен и Telegram ID администратора:

```dotenv
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789
MANAGER_IDS=
MANAGER_CHAT_ID=
```

Если вы ещё не знаете свой Telegram ID, сначала укажите только `BOT_TOKEN`, запустите бота, отправьте ему `/start`, подтвердите политику конфиденциальности и выполните `/myid`. Остановите бота, внесите полученный ID в `ADMIN_IDS` и запустите снова.

Запустите бота:

```powershell
python bot.py
```

Бот использует long polling, поэтому для работы он должен оставаться запущенным. Чтобы остановить его, нажмите `Ctrl+C`.

## Настройка

- `BOT_TOKEN` — обязательный токен бота.
- `ADMIN_IDS` — Telegram ID администраторов; несколько ID можно разделить запятыми или пробелами.
- `MANAGER_IDS` — необязательные Telegram ID менеджеров.
- `MANAGER_CHAT_ID` — необязательный ID чата для заявок. Вместо настройки этой переменной администратор может отправить `/setmanager` в нужном чате.

Узнать свой Telegram ID можно командой `/myid`. Чтобы команда появилась и работала, сначала запустите бота и подтвердите политику конфиденциальности.

Роли также можно назначать через админ-панель. После добавления администратора или менеджера бот перезапускается.

## Команды бота

- `/start` — открыть главное меню или начать сценарий заново.
- `/contacts` — открыть экран контактов.
- `/myid` — показать Telegram ID пользователя и чата.
- `/admin` — открыть админ-панель (только для администратора).
- `/leads` — открыть заявки (для администратора или менеджера).
- `/setmanager` — назначить текущий чат местом получения заявок (только для администратора).

Доступные команды могут отображаться в меню Telegram в зависимости от роли пользователя.

## Данные и конфигурация

- `scenario.py` — сценарий, вопросы, варианты ответов и контакты.
- `prices.json` — базовые цены, коэффициенты и надбавки для расчёта примерной стоимости заявки.
- `prices.default.json` — исходные значения для кнопки сброса цен в админ-панели. Не редактируйте его, если хотите сохранить исходные настройки для сброса.
- `data/leads.csv` — сохранённые заявки; файл можно открыть в Excel.
- `data/settings.json` — настройки ролей, согласий и изменённых пунктов меню.
- `data/overrides.json` — тексты сценария, изменённые через админ-панель.
- `.env` — секретный токен и начальные настройки доступа; не публикуйте этот файл.

Перед использованием замените демонстрационные контактные данные и ссылку `https://example.com/privacy` в `scenario.py` на актуальные значения. Убедитесь, что политика конфиденциальности соответствует фактическому сбору и хранению данных.

Сделайте резервную копию папки `data`, если нужно сохранить заявки и настройки при переносе или переустановке проекта.
